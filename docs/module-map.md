# 模块拆分

## 产品模块

### 1. 项目首页

职责：

- 展示项目列表。
- 创建新项目。
- 打开已有项目。
- 通过项目卡片进入项目编辑流程。

关键规则：

- 项目按更新时间/创建时间倒序展示。
- 项目封面优先使用主角资产缩略图。
- 项目卡片上的设置入口用于重新进入项目配置。

### 2. 项目设置流程

职责：

- 管理项目剧本。
- 管理项目属性。
- 管理项目资产。
- 管理项目内模型选择。

关键规则：

- 首次创建项目后，应先完成项目剧本、项目属性、项目资产，再进入剧集流程。
- 项目属性是项目下所有剧集的统一标准。
- 项目风格是资产图、分镜提示词和视频生成的一致性基础。

### 3. 模型中心

职责：

- 在工作台层面管理 LLM、生图模型、视频模型和视频提示词标准。
- 项目内只选择使用哪个模型，不直接维护底层 endpoint/key。

当前模型用途：

- 剧本 LLM。
- 分集续写 LLM。
- 分镜 LLM。
- 资产提取 LLM。
- 提示词包 LLM。
- 资产生图模型。
- 故事板生图模型。
- 视频模型。
- 视频提示词标准。

### 4. 资产中心

职责：

- 管理角色、场景、道具。
- 展示资产缩略图、名称、提示词和历史图片。
- 支持手动上传、手动添加、模型生成。

关键规则：

- 项目资产库与剧集资产库是同一个库。
- 分镜提取出的资产应补充进项目资产库。
- 分镜生成时优先复用项目资产库，避免角色和场景漂移。
- 资产图生成必须继承项目风格。

### 5. 剧集侧边栏

职责：

- 展示当前项目下的剧集列表。
- 支持切换剧集。
- 支持新增剧集。

关键规则：

- 剧集属于项目。
- 剧集继承项目属性。
- 第 2 集以后，LLM 续写应参考上一集内容。

### 6. 分集剧本

职责：

- 管理当前剧集的剧本。
- 支持手动输入。
- 支持 LLM 生成/续写。

关键规则：

- 手动输入剧本后，分镜制作仍会使用 LLM 做结构化分镜。
- 分集剧本是分镜制作的直接输入。

### 7. 分镜制作

职责：

- 生成分镜脚本。
- 从分镜脚本提取资产。
- 生成 Seedance 2.0 提示词包。
- 在每个分镜上执行视频生成。

关键规则：

- 分镜提示词显示在“分镜制作-提示词”区域。
- 提示词可以按镜头切换查看，不需要全部展开。
- 提示词中的资产以引用标识融入文本，不强行塞入所有资产。

### 8. 分镜剪辑

职责：

- 展示视频片段生成结果。
- 刷新和查看视频任务状态。
- 为后续剪辑、排序、成片输出预留空间。

v1.0 边界：

- 当前只做到视频片段状态和预览。
- 自动剪辑成片不是 v1.0 范围。

### 9. 运行记录

职责：

- 集中展示模型调用、保存、生成、状态刷新等事件。
- 避免运行记录散落在每个页面底部。

关键规则：

- 运行记录用于排查流程问题。
- 生成失败时应保留错误信息。

## 工程模块

### 1. 本地服务

文件：

- `server.js`

职责：

- 提供静态文件服务。
- 提供本地 API 路由。
- 读写本地 JSON。
- 调用 LLM、生图、视频模型。
- 生成和规范化提示词结构。
- 管理运行任务和事件。

### 2. 静态前端

文件：

- `public/index.html`
- `public/app.js`
- `public/styles.css`

职责：

- 页面结构。
- 本地状态渲染。
- 表单交互。
- API 调用。
- loading、任务状态、弹窗、预览和导出。

### 3. 本地数据

目录：

- `data/`

职责：

- 存储项目配置。
- 存储模型配置。
- 存储项目和剧集状态。
- 存储运行记录。

注意：

- `data/*.json` 属于本地运行数据，不进入 Git。

### 4. 生成缓存

目录：

- `cache/images/`
- `cache/videos/`

职责：

- 缓存上传或生成的图片。
- 缓存早期 mock 视频 HTML。

注意：

- 真实视频结果来自外部视频任务 URL。
- 缓存文件不进入 Git。

### 5. 启动脚本

文件：

- `start-workbench.bat`

职责：

- 检查 8800 端口是否已有服务。
- 检查 Node.js 是否存在。
- 启动本地服务并打开浏览器。
