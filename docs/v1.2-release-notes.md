# v1.2 Release Notes

Release date: 2026-06-03

## Version goal

v1.2 clarifies how project dialogue language is used in the AI short-drama workflow. The project dialogue language now controls spoken dialogue and generated voice only, while visual production guidance can remain in Simplified Chinese for easier review and editing.

This keeps the existing Seedance 2.0 generation flow intact and avoids changing the video API payload, reference image upload flow, or project data structure.

## Key updates

### Dialogue language scope

- `dialogueLanguage` is now treated as the spoken dialogue and voice language.
- Script summaries, shot actions, camera instructions, sound design, continuity notes, and visual production guidance may remain in Simplified Chinese.
- Character names, asset ids, and `@asset` references are preserved and are not translated automatically.

### LLM prompt rules

- Project script generation now tells the LLM to output non-spoken production fields in Simplified Chinese while keeping dialogue lines in the project dialogue language.
- Episode script generation follows the same rule, so continuation scripts stay easy to review.
- Shot generation keeps camera/action/visual notes in review-friendly Chinese and writes only spoken shot dialogue in the selected dialogue language.
- Seedance prompt package generation keeps visual and sound guidance readable in Chinese, while `dialogue[].text` and `dialogue[].voice` follow the selected dialogue language.

### Seedance submission language rule

- The final Seedance prompt now includes an explicit speech language block.
- For non-Chinese dialogue languages, the prompt states that Chinese text is only production guidance and must not be spoken.
- If a dialogue line is accidentally written in another language, Seedance is instructed to express its meaning in the target spoken language instead of speaking the source language.

### Frontend preview and guidance

- The project settings UI now explains that dialogue language only controls character dialogue and video voice.
- The "actual submission content" preview now includes the same speech language rule that the backend sends to Seedance.

## Rollback

To inspect v1.1:

```powershell
git checkout v1.1
```

To create a maintenance branch from v1.1:

```powershell
git switch -c release/v1.1 v1.1
```

To revert v1.2 on a branch:

```powershell
git revert <v1.2-merge-commit>
```
