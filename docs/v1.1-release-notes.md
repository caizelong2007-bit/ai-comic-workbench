# v1.1 Release Notes

Release date: 2026-06-02

## Version goal

v1.1 builds on the v1.0 MVP and focuses on improving the short-drama production flow after the video model was connected. The goal is to keep the existing project -> episode -> shot -> asset -> Seedance prompt -> video generation pipeline stable, while making shot scripts, prompt packages, and video submission behavior easier to inspect, edit, and manage.

## Key updates

### Shot script editing

- Added a dedicated shot script edit entry from the shot-making view.
- Shot script content is shown in a fixed-width preview on the first-level page.
- Longer shot text can be edited in a secondary modal instead of expanding the main page.
- Editing a shot script marks related prompt packages and videos as needing confirmation/regeneration.

### Shot script and asset extraction standard

- Added `docs/shot-script-asset-extraction-standard.md`.
- Defined how episode scripts should be split into 6-10 roughly 15-second shots.
- Clarified that one 15-second shot can contain a coherent micro-beat rather than only one tiny action.
- Added continuity rules for maintaining narrative flow between shots.
- Added asset extraction rules for visible characters, locations, props, recurring objects, and hidden-but-important story objects.

### Prompt package job status

- Improved prompt package generation status handling.
- Stale or stuck prompt jobs can recover instead of staying in an endless loading state.
- The UI now allows browsing other shots while prompt generation is running.
- Failed prompt generation shows clearer status instead of silently blocking the row.

### Prompt package editing and stale detection

- Human-readable prompt package fields remain editable.
- Asset mentions are kept inline with the editable text, so `@asset` references can be edited as part of the sentence.
- Saving manual prompt changes updates the stored package and marks existing videos as stale when needed.
- Video generation buttons now warn or block appropriately when the prompt package is stale.

### Seedance 2.0 submission prompt cleanup

- Frontend preview/export and backend video submission now use the same final prompt structure.
- The actual video submission prompt no longer places raw shot text such as `Shot`, `Camera`, or generic asset descriptions at the highest priority.
- The final Seedance prompt is ordered as:
  1. Generation instruction
  2. Reference image binding
  3. Project visual style
  4. Timed sub-shot prompt content
  5. Sound design
  6. Audio timeline
  7. Dialogue
  8. Final constraints
- Reference image binding explicitly tells Seedance how to use character, location, and prop references.
- This reduces the chance that broad shot text overrides the actual reference images.

No model request is required for the release check itself.

## Rollback

To inspect v1.0:

```powershell
git checkout v1.0
```

To create a maintenance branch from v1.0:

```powershell
git switch -c release/v1.0 v1.0
```

To revert the v1.1 release on a branch, revert the v1.1 merge commit or reset to the previous release tag according to the release policy.
