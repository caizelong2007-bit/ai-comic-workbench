# v1.0 MVP 范围

## 版本定义

v1.0 是 AI 漫剧工作台的第一个可运行 MVP。它使用零依赖 Node 本地服务、静态前端、本地 JSON/文件缓存，并接入 LLM、生图模型和 Seedance 2.0 视频生成模型。

v1.0 的目标不是完成完整剪辑软件，而是验证短剧生产主链路：

```text
项目配置 -> 项目剧本 -> 项目资产 -> 分集剧本 -> 分镜脚本 -> 分镜资产 -> 分镜提示词包 -> 分镜视频片段
```

## 已完成能力

### 项目层

- 项目列表展示，支持创建和打开项目。
- 项目按最近创建/编辑倒序排列。
- 项目封面优先使用主角资产图，无资产图时使用默认占位。
- 每个项目可独立维护项目剧本、项目属性、项目资产和模型选择。
- 项目属性会应用到项目下所有剧集。

### 项目配置

- 支持项目剧本输入和 LLM 生成。
- 支持视频风格配置。
- 支持自定义风格：风格名称、风格提示词、风格参考图。
- 支持基础视频属性：比例、视频长度、字幕开关、对白语言。
- 支持平台级模型中心，项目内只保留模型选择入口。

### 资产中心

- 项目资产库包含角色、场景、道具。
- 支持手动添加资产。
- 支持从剧本/分镜中自动提取资产。
- 支持同名、别名、角色称呼合并，减少重复资产。
- 资产在同一个项目的多个剧集中复用。
- 支持资产图上传、生成、历史记录和切换选择。
- 资产图生成会应用项目风格提示词，并可使用项目风格参考图。

### 剧集层

- 一个项目下支持多个剧集。
- 剧集列表放在左侧侧边栏，支持切换和新增。
- 新建剧集支持空白、手动输入、LLM 续写。
- LLM 续写可参考上一集内容，保持故事连续性。
- 剧集默认继承项目视频属性。

### 分镜制作

- 支持将分集剧本生成 15s 分镜脚本。
- 支持按分镜提取重要资产。
- 支持控制单段分镜参考资产上限，当前按最多 4 张参考图管理。
- 支持生成 Seedance 2.0 标准分镜提示词包。
- 提示词包中包含分镜提示词、音效、台词、资产引用。
- 分镜提示词预览和导出的内容保持一致。

### 视频生成

- 已接入 APIMart Seedance 2.0。
- 使用 480p 分辨率。
- 支持异步提交视频任务并轮询任务状态。
- 支持把本地资产参考图上传到 APIMart，再传入视频模型。
- 支持在视频生成后展示任务状态、视频 URL 和预览。
- 重新生成提示词后，旧视频会被识别为可能过期，需要按新提示词重新生成。

## 未纳入 v1.0 的能力

- 分镜片段自动剪辑成完整单集成片。
- 多轨时间线编辑。
- 字幕文件自动生成与烧录。
- 音频/配音模型接入。
- 多人协作和云端账号体系。
- 项目导入/导出包。
- 自动化测试体系。
- 多视频模型完整切换标准。

## v1.0 验收边界

只要一个项目可以完成以下链路，就认为 v1.0 主流程成立：

1. 创建项目。
2. 设置项目剧本、项目属性、项目风格和项目资产。
3. 创建分集。
4. 生成或填写分集剧本。
5. 生成分镜脚本。
6. 提取分镜资产并生成资产图。
7. 生成 Seedance 2.0 分镜提示词包。
8. 使用提示词包和参考资产生成分镜视频片段。
9. 工作台能展示视频任务状态和最终视频结果。
