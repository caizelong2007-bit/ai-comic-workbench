# 制作流程

## 总览

v1.0 的主流程围绕“项目 -> 多剧集 -> 单集分镜 -> 视频片段”组织。

```text
创建项目
  -> 设置项目剧本
  -> 设置项目属性和风格
  -> 建立项目资产库
  -> 创建剧集
  -> 生成/填写分集剧本
  -> 生成分镜脚本
  -> 提取和复用资产
  -> 生成资产参考图
  -> 生成 Seedance 提示词包
  -> 生成视频片段
```

## 1. 创建项目

输入：

- 项目名称。
- 整部短剧剧本或故事梗概。

输出：

- 项目记录。
- 初始项目配置。
- 初始项目状态。

项目创建后，不应直接跳到分集制作，而是先完成项目级设置。

## 2. 项目剧本

输入来源：

- 用户手动粘贴。
- LLM 生成。

用途：

- 作为整部短剧的故事基础。
- 作为资产提取和分集续写的背景。
- 作为分集创建时的继承上下文。

## 3. 项目属性与风格

配置内容：

- 视频风格。
- 风格参考图。
- 风格提示词。
- 视频比例。
- 视频长度。
- 字幕开关。
- 对白语言。

用途：

- 约束资产图生成。
- 约束分镜提示词生成。
- 约束 Seedance 视频生成参数。

项目风格应被视为项目内所有视觉输出的统一标准。

## 4. 项目资产库

资产类型：

- 角色。
- 场景。
- 道具。

资产来源：

- 手动添加。
- 从项目剧本提取。
- 从分镜脚本提取。

资产图来源：

- 用户上传。
- 生图模型生成。
- 历史记录中切换选择。

复用规则：

- 同一项目下多个剧集共享资产库。
- 分镜生成时优先匹配已有资产。
- 名称、别名、角色身份、常用称呼都可作为匹配依据。

## 5. 创建剧集

创建方式：

- 空白剧集。
- 手动输入剧本。
- LLM 续写。

继承规则：

- 默认继承项目属性。
- 默认使用项目资产库。
- 续写时参考项目剧本和上一集内容。

## 6. 分集剧本

分集剧本是当前剧集的核心文本。

后续分镜制作不会直接使用项目总剧本替代分集剧本；如果分集剧本为空，才会临时继承项目剧本作为输入。

## 7. 生成分镜脚本

输入：

- 当前分集剧本。
- 项目属性。
- 项目风格。

输出：

- 15s 分镜列表。
- 每个分镜包含镜头编号、场景、动作、构图、台词、音效、视觉说明等。

## 8. 提取分镜资产

输入：

- 单个分镜或多个分镜。
- 当前项目资产库。

输出：

- 新增或合并后的角色、场景、道具。
- 每个分镜关联的重要资产。

规则：

- 单个分镜最多选择 4 个核心参考资产。
- 优先选择对画面一致性影响最大的资产。
- 主角、主要配角、核心场景、关键道具优先。
- 氛围、普通背景元素、一次性小物件可不作为参考资产。

## 9. 生成资产参考图

输入：

- 资产卡。
- 项目风格提示词。
- 项目风格参考图。

输出：

- 资产参考图。
- 资产图历史记录。

参考图标准：

- 人物：三视图或稳定角色设定图。
- 场景：多角度或清晰空间设定图。
- 道具：清晰外观、可复用、避免复杂背景干扰。

## 10. 生成 Seedance 提示词包

输入：

- 分镜脚本。
- 分镜关联资产。
- 资产图。
- 项目属性和风格。

输出：

- 结构化提示词包。
- 可预览的分镜提示词。
- 可导出的提示词包。

提示词包用于工作台管理；真正提交给视频模型时会被转换为精简视频请求。

## 11. 生成视频片段

输入：

- 当前分镜的 Seedance 提示词。
- 对应参考资产图。
- 项目视频参数。

提交给 Seedance 的核心内容：

- `prompt`：精简后的分镜视频提示词。
- `image_urls`：上传到 APIMart 后得到的参考图 URL。
- `resolution`：480p。
- `size`：由项目比例映射。
- `duration`：由分镜/项目长度约束。
- `generate_audio`：根据字幕、对白、音效配置判断。

输出：

- 视频任务 ID。
- 任务状态。
- 视频 URL。
- 成本、进度、错误信息等附加信息。

## 12. 分镜剪辑与输出

v1.0 状态：

- 展示每个分镜的视频片段。
- 支持刷新任务状态。
- 支持重新生成视频。

后续预留：

- 调整片段顺序。
- 拼接单集成片。
- 导出最终视频。
- 生成字幕和音频轨。
